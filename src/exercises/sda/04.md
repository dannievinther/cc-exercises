title: Hold boksen fast med sticky

  .container {
    view-timeline: --container;
    height: 200vh;
  }
  .sticky-element {
    position: sticky;
    top: 0;
    height: 100vh;
  }
  .box {
    place-self: center;
    animation: spin linear both;
    animation-timeline: ;
  }
  @keyframes spin {
    to {
      rotate: 360deg;
    }
  }
startingHTML: |
  <div style="height:100%"></div>
  <div class="container">
    <div class="sticky-element">
      <div class="box">I'm a box</div>
    </div>
  </div>
  <div style="height:100%"></div>
hints:
  - { type: property, name: "view-timeline" }
  - { type: property, name: "animation-timeline" }
  - { type: value, name: "--container" }
---

Boksen ligger i et sticky-element, som bliver stående øverst, mens den højere `.container` scroller forbi. Få boksen til at rotere 360 grader under containerens passage gennem scrollporten.

Containeren har allerede en navngiven view-timeline: `--container`. Brug den som `animation-timeline` på `.box`, så animationen følger containeren.

Slå **Debug** til for at se containerens og sticky-elementets grænser. Scroll begge veje, og læg mærke til, hvornår sticky-elementet bliver holdt fast og slipper igen.
