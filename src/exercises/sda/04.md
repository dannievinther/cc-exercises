startingCSS: |
  .container {
    view-timeline: --container;
    height: 200vh;
  }
  .sticky-element {
    position: sticky;
    top: 0;
    height: 100vh;
  }
  .box {
    place-self: center;
    animation: spin linear both;
    animation-range: contain;
  }
  @keyframes spin {
    to {
      rotate: 360deg;
    }
  }
startingHTML: |
  <div style="height:100%"></div>
  <div class="container">
    <div class="sticky-element">
      <div class="box">I'm a box</div>
    </div>
  </div>
  <div style="height:100%"></div>
hints:
  - { type: property, name: "animation-timeline" }
  - { type: value, name: "--container" }
---

Få boksen til at rotere 360 grader, mens sticky-elementet bliver holdt fast. Brug containerens navngivne timeline `--container` som `animation-timeline` på `.box`.

`animation-range: contain` er allerede angivet. Slå **Debug** til for at se containerens og sticky-elementets grænser.
