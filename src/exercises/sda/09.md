    display: grid;

    overflow-y: auto;

  .box {
    place-self: center;

  @keyframes rotate {

    }

Få scroll i venstre panel til at rotere boksen i højre panel 180 grader. Brug `timeline-scope` på den fælles forælder `.scrollport`, så begge paneler kan bruge timelinen `--scroll`.

Timelinen er allerede defineret på `.scroller` og angivet som `animation-timeline` på `.box`, som ligger uden for `.scroller`.
